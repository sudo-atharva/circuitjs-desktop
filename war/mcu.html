Microcontroller (MCU)

A small programmable chip (Digital Chips → Add Microcontroller). It has 8 pins, P0–P3 on the left and P4–P7 on the right, and runs the program in its edit dialog: read buttons and sensors, drive LEDs, wait with delay. Hover over it to see the current line, every pin and your variables.

Example: blink, stop with a button, speed from a knob

# LED (with resistor) on P0, button from P1 to ground, potentiometer wiper on P2
pullup P1
loop
if P1 == 1          # not pressed (the pull-up keeps it high)
  P0 = 1
  delay 100 + A2 * 180
  P0 = 0
  delay 100 + A2 * 180
else
  P0 = 0
end

Language

# text, // textcomment
looplines above it run once at start (setup), lines below repeat forever. Without loop the whole program repeats.
P0 = 1set a pin high (5 V) or low (0); this makes it an output. Any non-zero value is high.
pullup P1 P2inputs with the internal pull-up (20 kΩ to 5 V), for buttons to ground
delay 500wait, in milliseconds (any expression, e.g. delay A2 * 100)
x = A2 * 2variable
if … else … endcondition
while … endrepeat while true. A loop without delay checks once per simulation step, so while P1 == 1 / end waits for a button.

In expressions:

P3digital read: 1 above 2.5 V, else 0. An output reads back what it was set to, so P0 = not P0 toggles.
A3the pin's voltage in volts (analog read)
millissimulation time in ms
operators+ - * / %, == != < > <= >=, and or not (or && || !), ( )

Timing

Like a real MCU, the program takes time: every pin write that changes a pin takes one simulation time step, so a pulse such as P1 = 1 / P1 = 0 always reaches the circuit. Everything else (math, if, reading pins) takes no time; a loop without delay still checks only once per time step.

Electrical model

5 V part. Output pins drive 0 / 5 V through about 25 Ω (so an LED still needs its resistor). Inputs draw almost nothing (100 MΩ). With pullup an input is pulled to 5 V through 20 kΩ.

Errors (with the line number) show in the info box, and the chip label reads MCU !. Reset the simulation to run the program from the start.
