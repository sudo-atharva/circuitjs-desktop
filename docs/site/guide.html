Guide & tips

Everything here works the same in the desktop app and in the browser version (except files, PDF and MCP, which are desktop only).

Basics

The circuit runs all the time, like a real board on the bench. Yellow dots show current flowing; wire colors show voltage (green positive, red negative, gray 0 V).

Drawing a circuit

  1. Pick a part in the Draw menu, or press its key (r resistor, w wire...).
  2. Drag on the canvas from one end to the other. Ends snap to the grid.
  3. Wires connect where their end points meet another end point or a pin. Two wires crossing in the middle are not connected.
  4. Every circuit needs a ground (g) or a source with a ground reference.
Tip: drag a part's end dot to move only that end. Ctrl+R rotates, Ctrl+D duplicates. Ctrl+click a wire to split it.

Values and units

Type values with SI prefixes: 4.7k, 100n, 2.2u (µ), 1M (mega), 10m (milli). Times in the Waveform Viewer work the same: 500u = 500 µs.

Tip: m is milli and M is mega. A 1m resistor is 0.001 Ω.

Measuring

Probes (best way)

Press h, click a wire, drag the handle out. Each probe is a colored channel (CH1 yellow, CH2 cyan...) in the Waveform Viewer. A probe on a wire measures that node to ground. Drag it anywhere, even while running. A hollow tip with ? means it is not touching anything.

Small scopes

Right-click a part → View in Scope puts a small graph at the bottom. It shows max, min and frequency. Right-click the graph for its options (stack, combine, properties).

Frequency

The small scopes and the viewer time the rising edges over many periods, so square waves read correctly even when edges fall between time steps (1 to 60 kHz within 0.3 % at the default 5 µs step). Above about 1 / (3.3 × time step) there are too few samples per cycle: lower the time step in Options → Other Options.

Waveform Viewer

Opens when you add a probe, or double-click a small graph (or right-click it → Open in Waveform Viewer).

The readout under the plot, per trace: peak-to-peak, min, max, average, RMS, frequency, duty, and on a second line rise / fall time (10-90 %) and slew rate. With cursors: the value at A and B, the difference, slope A→B and the slope at A (V/s or A/s).

Tip: to measure a slope, zoom to the edge first: the slope at a cursor is taken over 1/500 of the visible time span.

MCU block

Draw → Digital Chips → Add Microcontroller (MCU). 8 pins: P0-P3 on the left, P4-P7 on the right. Double-click it to edit the program; hover it to see the running line, every pin and your variables.

# LED on P0 blinks while the button on P1 is not pressed,
# a knob on P2 sets the speed
pullup P1           # button to ground, internal pull-up
loop                # lines above run once, lines below forever
if P1 == 1
  P0 = 1
  delay 100 + A2 * 180   # A2 = voltage on P2 (0-5 V)
  P0 = 0
  delay 100 + A2 * 180
else
  P0 = 0
end
WriteMeaning
P0 = 1pin high (5 V); makes it an output. P0 = not P0 toggles.
pullup P1input with a 20 kΩ pull-up
P3 / A3read: 1/0 (above/below 2.5 V) / the voltage
delay 500wait 500 ms (any expression)
x = x + 1variables
if / else / end, while / endblocks
millissimulation time in ms
operators+ - * / %, == != < > <= >=, and or not
Tips: outputs drive through about 25 Ω, so LEDs still need a resistor. Each pin change takes one time step, so P1 = 1 then P1 = 0 is a real (5 µs) clock pulse. A while loop without delay checks once per time step, so while P1 == 1 / end waits for a button. An error shows its line number in the hover info and the chip reads MCU !.

Practical circuit tips

  • LED resistor: R = (supply - LED voltage) / current. 5 V red LED at 10 mA: (5 - 2) / 0.01 = 300 Ω, use 330 Ω.
  • Transistor as a switch: give it about 1/10 of the load current as base current so it saturates. Hover it: it should say saturation and Vce well under 0.3 V. In fwd active it heats up.
  • PNP high side: the base needs to go down to near the emitter supply minus 0.7 V; a 10 kΩ base-emitter resistor keeps it off. To switch it from 5 V logic when the load is 12 V, use an NPN to pull the base down (see the PNP example).
  • Optocoupler inputs: 24 V inputs usually use 3.3-4.7 kΩ (about 5 mA). The output side inverts with a pull-up: LOW = input on.
  • Short-circuit protection: a fuse cuts off; a current limiter (sense resistor + second transistor) holds the current at 0.65 V / Rsense but the transistor then takes the whole supply voltage: check its power (P in the hover info).
  • Logic inputs should never float: tie unused inputs to 5 V or ground (a floating input reads 0 V here, but not on a real board).

Simulation tips

  • Time step (Options → Other Options): default 5 µs. Use 20+ samples per cycle for waveforms whose shape matters (about 10 kHz at 5 µs). Smaller steps run slower.
  • Slow circuits (seconds) at a small time step take long: raise the time step, or use Run for in the viewer, which runs at full CPU speed.
  • Ideal parts can make impossible circuits: two voltage sources in parallel, or a source shorted by a wire, give an error. Add a small resistance.
  • Use Edit → Undo (Ctrl+Z) freely: every change can be undone.

Files and PDF

  • File → Save writes a .csim file (plain text). Double-click a .csim to open it (installer version).
  • File → Export Datasheet (PDF): an editable A4 datasheet; Save as PDF / Print → Microsoft Print to PDF. Put probes on the nodes you care about first: they become the measured characteristics and waveform figures.
  • Export CSV in the Waveform Viewer saves the traces for Excel or Python.

AI control (MCP)

Desktop app: Options → Enable MCP Server. Then, in Claude Code:

claude mcp add --transport http --scope user circuitjs http://127.0.0.1:7432/mcp

Ask things like "build a 555 at 1 kHz and check the duty cycle". The AI edits single lines (edit_circuit) so a change costs a few hundred tokens. Full guide: docs/MCP.md.

Troubleshooting

ProblemFix
Nothing happens, the time does not movePress RUN / Stop; check for an error message at the bottom.
"Singular matrix" / "no path to ground"A node has nothing connecting it to the rest: add a ground, or a high resistor (1 MΩ) to ground.
A part does not connectWires only join at end points: drag the end onto the pin until it snaps.
No frequency shownThe signal needs 2-3 full periods with the same timing; for fast signals lower the time step.
Waveform Viewer not visibleDouble-click a small graph again: the window comes to the front.
SmartScreen blocks the downloadMore info → Run anyway (the app is not code-signed yet).
